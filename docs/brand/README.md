# Halkvakts varumärke

Det här är varumärket som gäller för appen, halkvakt.se, varningskorten, annonserna och inläggen. Läs guiden innan du skriver text eller ritar något som bär Halkvakts namn.

| Fil | Vad |
|---|---|
| `VARUMARKESGUIDE.md` | Varumärkesguide 1.0 (okt 2026): kärnan, logotypen, färgerna, typsnitten, ikonerna, komponenterna, varningskortet, röst och ton. |
| `SOCIALA-MALLAR.md` | De tre mallarna för inlägg: Halkvakt live, Dagsläget, Så funkar Halkvakt. |
| `BESLUT.md` | Varumärkesbesluten med datum, och de öppna frågorna. |
| `halkvakt-mark.svg` | Logomärket: triangeln med utskuret utropstecken. |

## Källan

Filerna här är textkopior. Källorna är Claude Design-filerna som länkas överst i varje fil. Ändra i Design-filen först och uppdatera sedan texten här.

## Det som inte längre gäller

`docs/DESIGN-BRIEF.md` (1 september 2026) är underlaget som appens skinn ritades från. Dess färger (#FFC400, #06090D, #0E1B25) och typsnitt (SF Mono, JetBrains Mono) är ersatta av guiden. Använd guidens värden.
