# Bilaga 2 — Rekryteringsplan för testförare

*Halkvakt, ansökan till Skyltfonden 2026. Gäller arbetspaket 3.*

## Syfte

Testförarna ger projektets förarfacit: efter varje varning svarar de *stämde* eller *stämde inte*, och efter resan kan de markera en halka appen missade. Svaren läses mot tre andra facitkällor: väglagskameror, SMHI:s varningar och stationernas egna mätserier. Förarna besvarar också den enkät och gruppintervju som är projektets mått på hur varningen påverkar körningen.

## Plan

| | |
| :-- | :-- |
| **Antal** | 30–50 testförare, med sikte på 40 som fullföljer vintern (kostnadsplanens 40 presentkort). |
| **Vilka** | Förare som kör regelbundet vintertid, främst i Skåne: pendlare, förare som kör landsväg i mörker och, där det går, yrkesförare. B-körkort; ingen annan gräns. |
| **Kanaler** | Projektgruppens kontaktnät, projektets webbplats och sidor i sociala medier, lokala forum och föreningar samt direkt kontakt. Testförarna är en känd krets: var och en bjuds in personligen. |
| **Tidsplan** | Testkretsen byggs på egen bekostnad hösten 2026. Från januari 2027 ingår uppföljning, kompletterande rekrytering och analys i AP3. Inför andra vintern (nov 2027–mar 2028) tillfrågas samma förare först. |
| **Vad testföraren gör** | Har appen igång vid vinterkörning. Slår själv på förarsvaren. Svarar *stämde* eller *stämde inte* när det går säkert. Markerar efter resan om appen missade något. Besvarar enkäten i april. |
| **Ersättning** | Ett presentkort på 500 kr för fullföljd vinter, det vill säga appen använd under vintern och enkäten besvarad. Ersättningen är inte kopplad till antalet svar eller till vad svaren säger. |
| **Enkät och gruppintervju** | April 2027 och april 2028. Frågorna gäller upplevd träffsäkerhet, om rösten stör, om appen behålls, om föraren sänkte farten eller ökade avståndet vid varning, och vilken formulering av varningen föraren helst vill ha. |

## Samtycke och data

- **Omkopplaren är avslagen från början.** Appens text vid den säger vad som skickas: varningens id, tidpunkt och svar, eller en markerad miss med tidpunkt, närmaste mätstation och vad det var. Texten säger också att ett svar pekar ut ungefär var och när föraren var (skärmbilden finns i bilaga 6).
- **Ingen position, inget GPS-spår och ingen hastighet lämnar telefonen automatiskt.** Inget konto, inget enhets-id och ingen IP-adress sparas.
- **Kontaktuppgifterna** för presentkort och enkät hålls av projektledaren, åtskilda från appens data, och kan inte kopplas till svaren. De raderas när projektet avslutas.

## Säkerhet

Instruktionen till testförarna säger uttryckligen att de svarar först när det är säkert, eller efter resan. En svarsknapp får aldrig ta blicken från vägen. På iPhone kan *stämde inte* och *appen missade* också sägas till Siri, och alla svar kan ges i efterhand på skärmen *Efter resan*.
